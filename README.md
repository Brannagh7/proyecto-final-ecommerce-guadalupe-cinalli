# Talento Lab

## Descripción
Sitio web de una tienda online (e-commerce) desarrollado como Pre-Entrega del curso de Front-End JS de Talento Tech.

## Objetivo
Aplicar HTML, CSS, diseño responsivo con Flexbox, Grid y Media Queries, y publicar el proyecto online.

## Secciones
- Inicio
- Productos
- Reseñas
- Contacto (formulario con Formspree)

## Formulario de contacto
Se utilizó Formspree para recibir los mensajes sin programar un servidor: creé un formulario en formspree.io y puse su URL en el `action` del `<form>`, con `method="POST"`. Los mensajes llegan directo a mi correo.
